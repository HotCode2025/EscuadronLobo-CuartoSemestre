🌱 Explicación sencilla para quienes recién empiezan

Pensalo como un molde de galletitas 🍪. Un personaje es un molde que ya trae todo lo que hace falta: un nombre, un elemento (fuego, agua, tierra o aire) y sus vidas. Con ese mismo molde podés hacer 1 personaje o 10.000: todos salen armados igual, pero cada uno con su propio nombre y elemento.

Paso a paso

  1. Elegí cuántos querés. Tocá 100, 1.000 o 10.000, o escribí el número que prefieras en "Cantidad personalizada".
  2. Tocá "Generar". La computadora arma todos al instante y le da a cada uno un nombre y un elemento al azar.
  3. Mirá el resultado. Abajo aparece cuántos se crearon, cuánto tardó (en milisegundos: 1.000 ms es 1 segundo) y cuántos salieron de cada elemento.
  4. ¿Querés uno solo tuyo? En "Crear personaje personalizado" escribí un nombre, elegí su elemento y tocá "Crear personaje". Después lo vas a encontrar en el juego, en la lista "Personajes personalizados".

Las palabras difíciles, en criollo

Clase
El molde: la receta que dice cómo es un personaje.
Instancia (u objeto)
Cada personaje que sale del molde. Si hacés 100, tenés 100 instancias.
Herencia
Los personajes de Fuego, Agua, Tierra y Aire copian todo lo básico del molde general y le suman lo propio. Es como una familia: todos llevan el apellido, pero cada uno tiene su forma de ser.
Polimorfismo
Una misma orden ("atacar") que cada elemento cumple a su manera, con su propio poder.
Encapsulamiento
Las vidas están "guardadas" dentro del personaje: nadie desde afuera puede cambiarlas por error.

💡 Esto es una demostración: sirve para ver que, usando clases, el programa puede crear miles de personajes en un abrir y cerrar de ojos.

💻 Explicación con código para quienes programan

Cada personaje generado es una instancia de una clase (PersonajeFuego, PersonajeAgua, PersonajeTierra o PersonajeAire), y las cuatro heredan de una clase base Personaje. El generador arma la cantidad que le pidas combinando un nombre y un elemento al azar. 

class Personaje {
  #vidas               // encapsulado: no se toca desde afuera
  constructor(nombre, elemento) { ... }
  atacar() { return `${this.nombre} ataca` }
}

class PersonajeFuego extends Personaje {   // herencia
  atacar() { return `${this.nombre} 🔥 lanza una bola de fuego` } // polimorfismo
}
