¿Cómo funciona?

Cada personaje generado es una instancia de una clase (PersonajeFuego, PersonajeAgua, PersonajeTierra o PersonajeAire), y las cuatro heredan de una clase base Personaje. El generador arma la cantidad que le pidas combinando un nombre y un elemento al azar. 

class Personaje {
  #vidas               // encapsulado: no se toca desde afuera
  constructor(nombre, elemento) { ... }
  atacar() { return `${this.nombre} ataca` }
}

class PersonajeFuego extends Personaje {   // herencia
  atacar() { return `${this.nombre} 🔥 lanza una bola de fuego` } // polimorfismo
}
